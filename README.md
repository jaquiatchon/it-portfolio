# IT Student Portfolio — First Draft

A responsive static portfolio built with HTML, CSS, and JavaScript.

## Customize before publishing
1. Open `index.html`.
2. Replace `John Matthew A. Quiatchon`, `[Your Course and Year]`, `[Your Course]`, and `[Your Year]`.
3. Replace `jaquiatchon@ccc.edu.ph` in both the visible email button and its `mailto:` link.
4. Update the project descriptions and tool lists so they accurately describe your work.
5. Replace both `https://github.com/` project links with actual repository URLs, or link to a real project screenshot/demo.
6. Remove any skills you have not used yet.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new **public** GitHub repository (for example, `it-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-GITHUB-USERNAME.github.io/it-portfolio/`.
7. Open the URL in a private/incognito window to test it before submitting it to the LMS.

GitHub Pages publishing may take a few minutes. Do not submit the example URL; use the exact URL shown in your repository's Pages settings.
